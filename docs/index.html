03 / STATISTICAL ANALYSIS

대응표본 t검정 분석

동일 충돌 조건에서 Rule-Based와 PPO를 비교한 100쌍의 생성 자료에 대한 분석이야. 실제 측정 원자료를 받으면 별도 검증해야 해.

생성 데이터의 유의성은 실제 사고나 시뮬레이션에서 강화학습 효과가 입증되었다는 뜻이 아니야. 실제 같은 조건의 대응표본 CSV가 필요해.

같은 조건의 실험별 HIC15 CSV (선택)

필수 열: speed_kmh, mass_kg, direction, baseline_hic15, rl_hic15 (행마다 동일 사고조건의 대응쌍)
현재는 기본 생성 데이터만 표시합니다.
04 / DATA & METHOD

연구 데이터와 분석 기준

HIC15

머리 합성가속도(g)의 15ms 이하 구간에서 평균 가속도와 충격 지속시간을 결합한 지표입니다.

HIC15 = max[(t2−t1) × (구간 평균 가속도)^2.5], 0 < t2−t1 ≤ 0.015s

두개골 골절 추정 위험

P(AIS 2+ 두개골 골절) = Φ((ln HIC − 6.96352) / 0.84664)

HIC15를 성인 참조 위험곡선에 대입한 모델 예측값이며 실제 사고 골절 발생률이 아닙니다. HIC 175 미만은 원본 적합 자료 범위 밖 외삽값입니다.

NHTSA 원문 위험곡선 자료

통계 검정

t = 평균(기존−RL) / (차이값 표준편차 / √n); H₁: 평균 차이 > 0

생성 데이터의 p값은 가정된 표본 분포에서만 유효하고, 실제 정책 성능의 증거로 사용할 수 없습니다.
